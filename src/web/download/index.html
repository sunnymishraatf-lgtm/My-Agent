STEP 1

Download

Tap the button above to download the APK file to your phone.

STEP 2

Allow install

Open the file and allow “Install unknown apps” when Android asks. One tap, only for NEUTRON.

STEP 3

Open & add key

Open NEUTRON, go to Settings, paste your API key. The app updates itself from here on.

Your key, your models

Bring your own API key — it lives only on your phone and is sent solely with your requests. Choose AgentRouter, OpenRouter, or Nous, and run Hermes models end-to-end.

Self-updating

NEUTRON checks for new releases daily and installs them in-app. You never have to download an APK manually again.

What’s inside

  • Full maintenance flow: analyze → impact → plan → approve → verify → report
  • Stateless chat with client-side history
  • Repository cloning, job history, and an explicit human approval gate
