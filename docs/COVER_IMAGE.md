## Visual concept

Dark developer-tool aesthetic: deep navy/charcoal background, subtle
terminal-grid texture. Left-to-right flow of four connected nodes,
communicating the core story:

**Repository → AI agents → Verification → Safe software maintenance**

- **Node 1 — Repository:** a minimal code-folder / file-tree glyph.
- **Node 2 — AI agents:** three small agent dots working in parallel on the
  files (keep abstract — no robot clichés, no chat bubbles).
- **Node 3 — Verification:** a shield with a checkmark (tests + security).
- **Node 4 — Safe maintenance:** a clean, glowing file tree with a checkmark
  badge.

Connect the nodes with a thin pipeline line; put a small "human approval"
gate marker (a pause/checkpoint icon) between nodes 2 and 3 — approval is
the product's signature.

## NEUTRON branding

- Wordmark "NEUTRON" in a strong monospace/technical typeface, letterspaced.
- Accent color: electric cyan/teal on dark. Avoid purple-blue gradients,
  avoid stock "AI" imagery (no glowing brains, no generic robots).
- Overall feel: a serious developer tool, not a consumer app.

## Recommended dimensions / aspect ratio

- 1200 × 630 px (1.91:1) — standard lablab.ai / social cover.
- Keep critical text and the four nodes inside a centered 1000 × 520 px
  safe area so nothing is cropped in thumbnails.
- Export as PNG.

## Text that should NOT appear

- No fake metrics ("10x faster", "99% accuracy", user counts).
- No "IBM Bob" claims implying Bob is the runtime backend.
- No URLs, no version numbers, no "coming soon".
- No placeholder text (no lorem ipsum in the final export).
